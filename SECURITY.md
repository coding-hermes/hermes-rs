# Security policy

Hermes RS is an independent reimplementation and may not yet provide equivalent security guarantees to upstream Hermes Agent. Do not use it as a production drop-in until its relevant compatibility, threat-model, and release gates pass.

Report suspected vulnerabilities privately through the GitHub repository's security advisory process. Include affected version, reproduction steps, impact, and mitigations. Do not publish secrets, personal data, or exploit details in public issues.
