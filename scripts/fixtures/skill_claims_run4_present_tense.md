# Traps (stale run-4 coaching — negative control)

- **The adapter's `open` ignores wrong-typed flags** — `create: "yes"` / `1`
  behave as absent, answering `Io: unable to open database file` with no hint,
  and `read_only: "true"` is treated as false, so a caller who thinks they
  opened a read-only viewer gets a write-capable handle on the archive
  (`DF-HRS-114`).
